# Mascotas de estados de ánimo

Assets PNG con transparencia utilizados por el selector y la tarjeta de resultado.

| Archivo | Estado |
|---|---|
| `mood_happy.png` | Feliz |
| `mood_calm.png` | Tranquilo |
| `mood_tired.png` | Cansado |
| `mood_sad.png` | Triste |
| `mood_stressed.png` | Estresado |

Reglas de uso:

- mantener la proporción original;
- utilizar `BoxFit.contain`;
- no recortar ni recolorear;
- acompañar siempre la imagen con una etiqueta textual accesible;
- no comunicar el estado únicamente mediante color.
