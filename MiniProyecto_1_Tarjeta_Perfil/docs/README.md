# Recursos del proyecto

Esta carpeta conserva los recursos que permiten comparar el diseño previsto con la implementación real.

- [`mockups`](./mockups/): diseños y referencias exportadas desde OpenDesign.
- [`capturas`](./capturas/): capturas de la aplicación Flutter ejecutándose en Android.

Las imágenes deben usar nombres descriptivos y, cuando sea útil, indicar el dispositivo o tamaño de pantalla representado.
